# Legal and Ethical Use

This repository is for education, portfolio building, and authorized defensive security practice only.

Use the tools only on systems you own or systems for which you have clear, explicit, written permission. Unauthorized scanning, packet capture, password testing, OSINT investigation, subdomain enumeration, or web assessment may violate laws, contracts, acceptable-use policies, or platform terms.

No permission means no testing. Do not upload real passwords, private logs, API keys, personal data, confidential reports, or packet captures containing private traffic.
